<ProblemBox>
- noteの有料記事は、市場全体で本当にお金が動いているのか？
- 決算が好調なら、個人クリエイターも儲かっているのか？

<b>結論：note全体では有料コンテンツは確実に売れています。ただし、売上の約6割は上位1,000人に集中し、大半の個人には届いていません。</b>

決算が好調であることと、あなたの記事が売れることは別問題です。この記事では、note株式会社（5243）の2026年11月期第3四半期（3Q）決算と公表KPIを使い、数字を自分で検算しながら実態を確かめます。

分析に使ったのは、決算短信・決算説明資料の公表値と、note公式が公開しているクリエイター関連データです。なお2026年11月期の有価証券報告書は、決算期末（11月末）後の提出になるため、現時点では3Q時点の開示が最新です。

## 1. 決算の数字：会社は大きく伸びている

まず会社全体の業績です。

| 項目 | 2026年11月期 3Q累計（12〜8月） | 通期予想（上方修正後） |
| :--- | :--- | :--- |
| <b>売上高</b> | 4,058百万円（前年同期比+33.2%） | 5,650百万円（+36.4%） |
| <b>営業利益</b> | 849百万円（前年同期比+567.0%） | 1,100百万円 |
| <b>営業利益率</b> | 約20.9% | 約19.5% |
| <b>進捗率（売上）</b> | 71.8% | ― |
| <b>進捗率（営業利益）</b> | 77.2% | ― |

売上は3割超、利益は約5.7倍。数字だけ見ると「有料記事が飛ぶように売れている」と読みたくなります。

ただし、ここに落とし穴があります。利益の急拡大には、AI関連事業の拡大や全社的な費用抑制も寄与していると説明されています。<b>営業利益の伸びは、そのまま有料記事の売れ行きの伸びではありません。</b>有料記事の実態を見るには、売上ではなく流通総額（GMV）を分解する必要があります。

## 2. 売上から流通総額を逆算すると、年間約250億円

noteの売上は、個人向けのnote事業が約7割、法人向けのnote pro等が約2割強です。note事業の売上は、次の式で決まります。

<b>note事業の売上 ＝ GMV（流通総額）× テイクレート</b>

テイクレートは、プラットフォーム利用料（有料記事・メンバーシップ等は10%）に決済手数料（クレジットカード約5%）を足した値で、下限は15%と説明されています。この前提で、公表数値が整合するかを検算しました。

| 検算ステップ | 計算 | 結果 |
| :--- | :--- | :--- |
| 通期売上予想 | 5,650百万円 | 56.5億円 |
| note事業の売上（約7割） | 56.5億円 × 0.7 | 約39.5億円 |
| GMVに逆算（テイクレート15%） | 39.5億円 ÷ 0.15 | 約264億円 |
| 四半期GMV（60億円台）の年換算 | 60〜66億円 × 4 | 約240〜264億円 |

逆算値と四半期GMVの年換算が、ほぼ一致しました。<b>noteの年間GMVは約250億円規模</b>と見てよさそうです（筆者の概算）。前年同期比で二桁成長が続いています。

月間購読者数（有料コンテンツを購入するユーザー）は約80万人と開示されています。月あたりGMV約21億円を80万人で割ると、<b>1人あたり月約2,600円</b>。読者は平均して、毎月ランチ数回分を有料コンテンツに払っている計算です。

つまり「市場として売れているか」の答えは、はっきりイエスです。

## 3. 売上の約6割は上位1,000人に集中している

次に、その約250億円を誰が受け取っているかです。note公式が公開しているデータは次のとおりです。

| 指標 | 公表値 |
| :--- | :--- |
| 収益化を経験したクリエイター（累計） | 約20万人以上 |
| 年間売上トップ1,000人の平均年間売上 | 約1,515万円（月平均約126万円） |

ここから集中度を計算します。

| 計算 | 結果 |
| :--- | :--- |
| 上位1,000人の年間売上合計（1,515万円 × 1,000人） | 約151.5億円 |
| GMV約250億円に占める割合 | <b>約61%</b> |
| 上位1,000人が収益化経験者に占める割合（1,000 ÷ 20万） | 約0.5% |

<b>収益化経験者の0.5%が、GMVの約6割を稼いでいる</b>ことになります。公開情報の中には「7割以上」と紹介するものもあります。集計期間や分母の違いがあるため、本記事では「6〜7割」の幅で見るのが安全です。

残り約100億円を、それ以外の全クリエイターが分け合う構図です。note社は収益化者の収益分布（中央値など）を公表していないため、「月1万円以上稼ぐ人が何%か」は公式には確認できません。累計200万人超の投稿者を分母にすれば、安定して月1万円を超える人は1%未満だと推測されますが、これはあくまで推計です。

個人の検証例では、公開した有料記事の7〜8割が一度も購入されなかった、という報告もあります。これは特定個人のサンプルで、note全体の統計ではありません。ただ、集中度のデータとは矛盾しない結果です。

## 4. 月1万円・5万円に必要な販売本数を手取りで計算

「売れる人は売れる」だけでは判断材料になりません。手数料を引いた手取りで、必要な販売本数を計算しました。500円の記事を想定します。

| 決済手段 | 手数料合計 | 1本あたり手取り | 月1万円に必要な本数 | 月5万円に必要な本数 |
| :--- | :--- | :--- | :--- | :--- |
| クレジットカード | 約15%（利用料10%＋決済5%） | 約425円 | 24本 | 118本 |
| PayPay・Amazon Pay | 約17%（利用料10%＋決済7%） | 約415円 | 25本 | 121本 |
| キャリア決済 | 約25%（利用料10%＋決済15%） | 約375円 | 27本 | 134本 |

月5万円なら、毎月100本超を売る必要があります。1日3〜4本のペースです。記事単体でこれを続けるのは難しく、月額のメンバーシップや、SNSなど外部からの集客導線がないと成立しにくい水準です。

## 5. 売れているのは「実利」ジャンル、文字数は関係ない

note公式が約30万件の有料記事を分析した結果では、<b>有料部分の文字数と売上の相関はほぼゼロ</b>でした。長く書けば売れるわけではありません。

売れやすいと報告されているジャンルは、読者の行動や収入に直結するものに偏っています。

| 売れやすい | 売れにくい |
| :--- | :--- |
| AI活用・テクノロジー | 日記・エッセイ |
| SNS・コンテンツ運用ノウハウ | 一般的なライフスタイルの読み物 |
| 副業・在宅ワークの実践記録 | ファンがいない状態での身辺雑記 |

もう一つ構造的な問題があります。noteの読者には、自分も発信する側の人が多くいます。自分も売る側の人は、他人のノウハウ記事に払うハードルが高くなりがちです。「スキ」やフォロワーの数が、購入に直結するとは限りません。

## 6. 考察：note社は個人が儲からなくても儲かる構造

ここからは筆者の考察です。note社の収益は、GMVに手数料をかける構造です。個人クリエイターが儲かっているかどうかは、会社の売上に直接は影響しません。GMVが増えれば、誰の記事が売れても会社の売上は増えます。

さらに、売上の2割強を占める法人向けnote proは、月額型のストック収益です。個人の有料記事が売れなくても、法人側の売上が土台を支えます。

この構造は、投資家にとっては安定材料です。一方、個人にとっては次のことを意味します。

- プラットフォームの成長は、あなたの収益を保証しない
- 稼いでいるのは、すでに読者を抱える少数の書き手
- 新規参入者は、集客を自力で作る前提で考える必要がある

## 7. この分析の限界

本記事の数値には、次の限界があります。

- GMVには有料記事のほか、有料マガジン、メンバーシップ、サポート（チップ）が含まれます。<b>有料記事だけの売上は開示されていません。</b>
- 売上の逆算と集中度は、公表値をもとにした筆者の概算です。正確な値は、note社のIRページの決算説明資料で確認してください。
- 収益分布の中央値や、月1万円以上の人数は開示されていません。
- 本記事は投資助言ではありません。投資判断はご自身で行ってください。

## よくある質問（FAQ）

### Q1. 結局、noteの有料記事は売れているのですか？
市場全体では売れています。年間GMVは約250億円規模と推計され、前年から二桁成長しています。ただし売上の約6割は上位1,000人に集中しており、個人の大半は大きく稼げていません。

### Q2. 決算が好調なら、クリエイターも稼げているのですか？
別問題です。note社の売上はGMVに手数料をかけた構造で、利益の伸びにはAI関連事業や費用抑制も寄与しています。会社の好調と、個人の収益は連動しません。

### Q3. 月1万円稼ぐには何本売ればいいですか？
500円の記事で、手取り約425円（カード決済）なら月24本が目安です。月5万円なら約118本です。手数料は決済手段で変わります。

### Q4. 有料記事で売れやすいテーマはありますか？
AI活用、SNS運用、副業の実践記録など、読者の行動や収入に直結するジャンルが強いと報告されています。文字数と売上の相関はほぼありません。
